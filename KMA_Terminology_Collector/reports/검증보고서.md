## 남은 문제

1. 국내망에서 `--mode inspect` 를 실행해 실제 구조를 확인해야 합니다. 이후 `settings.yaml` 을 채우고 sample 로 파서를 검증합니다.
2. 목록이 검색어 입력 후에만 나오거나 전체 목록 조회가 안 되는 구조라면 초성·알파벳 분할 검색이 필요할 수 있습니다. 이 경우 분할 범위가 전체를 덮는지 증명할 수 없으므로 "전체 수집 완료"로 보고하면 안 됩니다(현재 미구현, 구조 확인 후 결정).
3. 사이트가 JavaScript POST(ASP `__doPostBack` 류)로만 페이지를 넘기면 `requests` 재현이 안 될 수 있습니다. 이 경우 inspect 의 `page2_navigation.request.post_data` 를 `fixed_params` 로 옮기거나 브라우저 기반 순회를 추가해야 합니다.
4. 사이트 표시 건수와 수집 행 수의 집계 기준(표제어 vs 행)이 다를 수 있어, 첫 실행 후 비교 기준을 확인해야 합니다.
5. 대량 수집은 의학용어위원회 승인 후에만 실행합니다(사이트 저작권 고지: 사전 승인 없는 전재·재배포 금지).

## 승인 후 실행 명령

```bash
python src/kma_collect.py --mode inspect
# settings.yaml 확정 후
python src/kma_collect.py --mode sample --max-pages 3 && python src/kma_collect.py --mode export
cp permission.example.json permission.json   # 승인 내용 기입, bulk_collection_allowed: true
python src/kma_collect.py --mode full   --authorization-file permission.json
python src/kma_collect.py --mode resume --authorization-file permission.json
python src/kma_collect.py --mode export
```
