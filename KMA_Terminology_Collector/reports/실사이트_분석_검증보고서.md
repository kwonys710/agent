## 2. 실제 HTML 구조
- **판 선택:** 사이트 메뉴는 `6.1판 / 5판 개정 / 5판 / 4판`. 별도의 "6판" 항목은 없음. 6.1판 = `$.sch_type(7)` → `sch_type=twdContent7/twdDong7`.
- **검색:** `$.search()`가 `proc.asp`에 AJAX POST로 결과 유무만 확인 → `$.commonSubmit("search_form","list.asp")` = **POST** 폼 제출.
- **A–Z 색인:** `$.spelling('a')` → `spelling_form` POST (`sch_type`, `sch_txt`, `sch_type_chk=7`, `spelling_chk=1`) = 앞글자 일치.
- **검색어 없이 전체 목록:** 불가. 6.1판 선택 후 빈 검색은 `총 0 개`.
- **페이지 이동:** 방식 **A (GET)** — `./list.asp?pageno=N&sch_txt=a&sch_type1=twdContent7&sch_type2=twdDong7`. 세션 상태에 의존하지 않음.
- **페이지당 15건**, 마지막 페이지는 `input.next_d`를 감싼 `<a href>`의 `pageno`.
- **결과 구조:** `p.total span`("총 N 개") / `dl.searchList` 안의 `<dt>`영문 `<dd>`한글. 검색어는 `<font color=#FF0000><b>`로 강조. 표 형식·상세 링크·용어 ID 없음.
- **`<dd>` 표지:** `[원]` 원어, `[동]` 동의어(한글 또는 영문), `[약]` 약어. 다의어는 `1. 유산  2. 낙태`, 복수 대응어는 `,`로 구분.

### 중요 결함: 페이지 링크가 검색 조건을 잃음
| 요청 | 총 건수 | 첫 행 |
|---|---|---|
| A–Z 색인 'a' 1페이지 (POST, spelling_chk=1) | 4,233 (283p) | A delta fiber |
| 사이트 링크로 이동한 2페이지 (GET, spelling_chk 없음) | **38,793** (2,587p) | ablation |
| GET 1페이지 (spelling_chk 없음) | 38,793 | 5-hydroxytryptamine |
| GET 2페이지 + `spelling_chk=1&sch_type_chk=7` | 4,233 | ablative laser |

사이트의 페이지 링크는 `spelling_chk`를 빠뜨려 2페이지부터 **부분 일치 검색으로 바뀐다**. 링크를 따라가면 서로 다른 결과 집합이 섞인다. 수집기는 링크를 따라가지 않고 `fixed_params`로 매 요청 URL을 직접 만든다. 앞글자 일치를 원하면 `spelling_chk: "1"`, `sch_type_chk: "7"`을 켠다. 페이지 간 총건수가 다르면 해당 페이지를 `failed`로 기록하고 중단한다.

## 4. 전체 데이터 확보 경로
**경로 B (웹 수집): 권장하지 않음.**
- robots.txt가 모든 자동 접근을 금지한다. 이용약관 페이지는 사이트에서 확인하지 못했다.
- 검색어 없이 전체 조회가 불가능하다. 글자별 검색으로 나눠도 영문 알파벳이 없는 항목(기호·숫자만 있는 용어 등)이 빠질 수 있고, 부분 일치 결과끼리 겹쳐 중복 제거가 필요하다. 사이트에 총 용어 수가 나오지 않아 완전성을 증명할 수 없다.
- 'a' 부분 일치만 38,793건(2,587페이지)이다. 전체를 수집하려면 수천~수만 번 요청해야 한다.

**경로 A (공식 DB): 권장.** 기존 조사(`../KMA_의학용어집_6판_조사/05_최종보고/KMA_6판_확보결과.md`, 판정 REQUEST_REQUIRED)와 일치한다.
